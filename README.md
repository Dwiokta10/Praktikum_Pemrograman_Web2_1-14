## 📖 Pendahuluan

## 🚀 Cara Menjalankan Proyek

Jika Anda ingin mencoba menjalankan proyek ini di komputer lokal Anda, ikuti langkah-langkah berikut:

### Persyaratan Sistem
- Node.js (untuk Vue.js)
- Web Server lokal seperti XAMPP/Laragon (jika menggunakan PHP/MySQL)
- Composer (opsional, jika menggunakan framework PHP)

### Langkah-langkah
1. Clone repositori ini atau ekstrak file yang telah diunduh.
2. **Untuk Lab 7:**
   - Pindahkan folder `Lab7Web` ke direktori web server Anda (misal: `htdocs` di XAMPP).
   - Akses melalui browser di `http://localhost/Lab7Web`.
3. **Untuk Lab 11 (Vue.js):**
   - Masuk ke direktori: `cd Lab11Web_VueJS`
   - Instal dependensi: `npm install`
   - Jalankan server development: `npm run dev` atau `npm run serve`
   - Akses URL yang diberikan di terminal (biasanya `http://localhost:5173` atau `8080`).
